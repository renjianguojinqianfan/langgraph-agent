langgraph>=1.2,<1.3

# The three packages are pinned together: they are the complete storage surface
# of the resume contract.
# - langgraph: patch-level only inside the 1.2.x LTS line; crossing a minor
#   goes through a fresh evaluation.
# - langgraph-checkpoint must be pinned explicitly: serde (JsonPlusSerializer)
#   lives in this package and is otherwise only constrained by upstream to a
#   floating window (currently [4.3,5)) -- one ordinary pip install could raise
#   it to 4.5 and change snapshot semantics. That would fail both the pin and
#   CHECKPOINT_FORMAT_VERSION (the marker only distinguishes pre/post migration,
#   not 4.x internal drift), and the failure mode is "silently corrupt resume".
# - langgraph-checkpoint-sqlite is pinned hard: the storage format directly
#   defines the resume contract.
# Upgrades must be evaluated and approved by a human. The previous pin 3.1.1
# closed two advisories that had been evaluated as "not_used" and dismissed on
# 2.0.11 (GHSA-9rwj-6rc7-p77c / CVE-2025-67644 and GHSA-47pj-3jcm-6whg /
# CVE-2026-71433), turning the security story from "accepted" to "fixed".
# The old rationale "3.x breaks resume serde compatibility" was disproved by
# measurement (3.1.1 reads 2.0.11 snapshots back losslessly); old snapshots are
# still invalid, but the reason is now "cross-major execution-position
# equivalence is unproven, and data/ is disposable", detected at startup and
# refused mount (task_manager.CHECKPOINT_FORMAT_VERSION).
#
# 2026-10-25 dual pin bump (#204, Dependabot alert #16): checkpoint 4.2.0 ->
# 4.3.0, sqlite 3.1.1 -> 3.1.2. Both fix Store namespace label validation
# (upstream #9217); 4.3.0 also keeps serialized data when serde rebuild fails
# (upstream #9251) and fixes delta replay ordering (upstream #8544/#9114);
# 3.1.2 also fixes empty checkpoint_id (upstream #9262) and delta ancestor
# traversal via parent pointers (upstream #8557). The langgraph row is
# unchanged: 1.2.11 accepts checkpoint >=4.1,<5, but the newest 1.2.x patch CI
# resolves (1.2.17 on 2026-10-25) requires checkpoint >=4.3.0,<5; sqlite 3.1.2
# does too, so both pins moved together. The old 4.2.0 combination cannot pair
# with the new langgraph. Repo conclusion: on-disk format is unchanged
# (CHECKPOINT_FORMAT_VERSION is still 2); the old database (written by
# 4.2.0/3.1.1) read back losslessly across 16/16 threads in measurement, so no
# migration or refusal is needed; resume/serde regressions are all green
# (evidence in the PR linked from #204).
#
# langchain-core 1.x comes in transitively via langgraph; this repo has zero
# "import langchain*", so langchain / langchain-openai / langchain-core are no
# longer pinned explicitly (the old langchain-core<0.3 pin directly conflicted
# with langgraph 1.x's >=1.0 requirement; removing it was a prerequisite of the
# upgrade).
# aiosqlite / sqlite-vec / ormsgpack are hard dependencies declared by
# checkpoint(-sqlite) and arrive with a normal install; only mcp needs
